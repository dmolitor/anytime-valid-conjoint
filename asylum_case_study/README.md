# European Asylum-Seeker Case Study

A real-data case study applying the anytime-valid AMCE method from the main
paper (see `../README.md`) to the 2016 wave of the Bansak, Hainmueller &
Hangartner conjoint experiment on European attitudes toward asylum seekers
(18,021 respondents; 5 forced-choice tasks each, between pairs of
hypothetical asylum-seeker profiles varying nine attributes).

## Reproducing

From the repository root:

```
bash asylum_case_study/run_all.sh
```

This will:

1. Run `code/01_prepare_data.R`, which cleans
   `data/raw/conjoint_data_2016.csv` (dropping 9 respondents/90 rows with
   every attribute missing) into `data/asylum_long.csv` (one row per
   respondent-task-profile).
2. Run `code/02_sequential_analysis.R`, which:
   - Sources the anytime-valid math (`t_radius`, `log_G_t`, `p_G_t`,
     `optimal_g`, `av_tidy`) from `../code/cj.R`, so this case study always
     uses the same formulas as the rest of the paper.
   - Fits the final model on all respondents and tidies it two ways:
     conventional fixed-$n$ (`broom::tidy`) and anytime-valid (`av_tidy`),
     saved to `data/final_comparison.csv` (all 27 non-intercept AMCEs).
   - Refits the model as respondents accumulate, stepping by 100
     respondents (182 fits from $G=5$ up to $G=18{,}021$, since refitting at
     every single respondent as the smaller camera case study does would be
     unnecessarily costly at this scale) to trace out each AMCE's confidence
     sequence and e-value over time, saved to
     `data/sequential_av_estimates.csv`.
   - Saves run metadata (total clusters, $\alpha$, the pre-registered
     $g^\star$, step size, and measured runtime) to `data/meta.csv`.
3. Render `report.Rmd` to `report.pdf` via `rmarkdown::render()`.

## Data

- `data/raw/conjoint_data_2016.csv` and `data/raw/conjoint_data_codebook.txt`
  are the source data: the 2016 wave of the conjoint experiment from Bansak,
  Hainmueller & Hangartner (2016, *Science*), as released in the replication
  archive for Bansak, Hainmueller & Hangartner (2023, *Nature*) via Harvard
  Dataverse (doi:10.7910/DVN/FTL1MM). See `report.Rmd`'s References section
  for full citations.
- Everything else under `data/` is generated by `code/01_prepare_data.R` and
  `code/02_sequential_analysis.R` and is not hand-edited.

## Notes on interpretation

- Respondents are processed in the order their 10-row blocks (5 tasks
  $\times$ 2 profiles) appear in the raw file to illustrate sequential
  monitoring; the dataset carries no survey timestamp, so this is a
  stand-in for true arrival order, not a claim about when respondents
  actually answered.
- $g^\star$ is optimized once for the actual final number of clusters
  ($G=18{,}021$) and held fixed while "replaying" the data sequentially --
  re-optimizing $g$ at each step using data-dependent information would
  invalidate the anytime-valid guarantee.
- With 27 non-intercept AMCEs (nine multi-level categorical attributes),
  the confidence-sequence and e-value evolution figures curate exactly one
  coefficient per attribute (the non-baseline level with the largest $|t|$
  statistic in the final full-sample fit); see the Method section of
  `report.Rmd` for the exact rule. The underlying CSVs and the final
  fixed-$n$-vs-CS comparison figure always retain all 27 coefficients.
